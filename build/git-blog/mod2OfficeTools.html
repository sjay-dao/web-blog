✅ Module 0: Digital Literacy Basics

Objective: Understand basic computer terms to help navigate office productivity tools.

🧠 What is a Computer?

A computer is an electronic device used to process information. It runs software programs that let us write, calculate, draw, browse the internet, and more.

🧩 What are Apps and Software?

Software or apps are programs that run on a computer or device. Some examples include:

  • Google Chrome (browser)
  • Google Docs (writing tool)
  • Microsoft Excel (data tool)

📁 What is a File?

A file is a digital document—like a letter, photo, or spreadsheet—that you save on a device.

  • resume.docx – Word file
  • budget.xlsx – Spreadsheet
  • presentation.pptx – Slides

💾 What is Storage?

Storage is where your files are kept, either on your computer or in the cloud.

  • Hard drives (inside your computer)
  • USB drives (portable)
  • Google Drive (cloud-based)

🌐 What is the Internet and a Browser?

The internet connects your computer to information around the world. A browser like Chrome lets you access websites.

✅ Why Learn These First?

  • To understand instructions like "Open this file" or "Use this app"
  • To save, share, and manage documents confidently
  • To feel more independent while using office tools

Module 1: Introduction to Office Productivity Tools

💡 What is Office Software?

Office software refers to programs used to create documents, presentations, spreadsheets, and more. These tools help with:

  • Writing and editing documents
  • Creating presentations
  • Organizing data using spreadsheets
  • Managing email and calendars
  • Collaborating in real time

Examples of Office Software:

  • Microsoft Office: Word, Excel, PowerPoint, Outlook
  • Google Workspace: Docs, Sheets, Slides, Gmail

🔄 Microsoft Office vs Google Workspace

Feature Microsoft Office Google Workspace
Access Installed on computer (desktop-based) Web-based (works on any browser)
Collaboration Limited real-time editing Real-time collaboration
Storage Files stored locally or in OneDrive Files saved automatically to Google Drive
Cost Paid (subscription or one-time purchase) Free with Google account (premium available)
Offline Use Works offline Offline mode available but needs setup

🔟 Creating a Google Account

If you don’t already have a Google account, now’s a good time to create one. A Google account gives you access to:

  • Gmail (email)
  • Google Drive (cloud storage)
  • Google Docs, Sheets, and Slides
  • Google Calendar
  • And much more!

Steps to create a Google Account:

  1. Go to accounts.google.com/signup
  2. Fill in your name and preferred email
  3. Create a strong password
  4. Follow the on-screen instructions to finish setup

✅ Summary

  • Office software helps with productivity and organization.
  • Microsoft Office and Google Workspace are the most popular options.
  • Google Workspace is ideal for collaboration and accessibility.
  • Create a Google account to start using Google’s free office tools.

Module 2: Google Docs (Word Processor Alternative)

Objective: Use Google Docs for writing, editing, and formatting documents.

✍️ Creating and Naming a Document

To start using Google Docs, go to docs.google.com and click the blank document icon. Don’t forget to name your document by clicking the title field on the top-left!

🎨 Basic Formatting

Format your text using options like:

  • Bold, Italics, and Underline
  • Change font styles and sizes
  • Adjust text alignment: left, center, right, justify

✉️ Paragraph Spacing, Bullets, and Numbering

Use spacing options for cleaner layout. Add bullet or numbered lists to organize your points.

🖼️ Inserting Images, Tables, and Links

Enhance your document by inserting:

  • Images (from computer, web, or Drive)
  • Tables to organize data
  • Hyperlinks to websites or email addresses

⚖️ Page Setup

Adjust margins, orientation, and page size under File > Page setup.

👥 Collaboration

Click the Share button to invite collaborators. Use:

  • Comments for feedback
  • Suggestions mode for trackable edits
  • Set permission to Viewer, Commenter, or Editor

⬇️ Downloading/Exporting

Export your document as a Word file, PDF, or other formats via File > Download.

✍️ Practice Activity:

Create a sample resume or meeting notes document using the skills above. Share it with a peer for feedback!

📊 Module 3: Google Sheets (Excel Alternative)

Objective: Use Google Sheets for data entry, calculations, and simple analysis.

🛋️ Spreadsheet Layout

Sheets are made up of cells organized into rows and columns. You can also use multiple sheets (tabs) in one file.

🔢 Data Types

Enter different types of data:

  • Text (names, labels)
  • Numbers (amounts, percentages)
  • Dates (for schedules or deadlines)

🛃 Basic Formatting

Use formatting tools to make your sheet clearer:

  • Merge cells
  • Add fill colors and borders
  • Use Conditional Formatting to highlight data

📈 Formulas

Try out basic formulas like:

  • =SUM(A1:A5) - adds values
  • =AVERAGE(B2:B10) - calculates average
  • =IF(C2>100,"Over Budget","OK") - adds logic

↕️ Sorting and Filtering

Sort data by alphabetical or numerical order, and filter to view only certain data.

🔍 Charts

Create simple charts to visualize your data: bar, line, pie, and more.

👥 Sharing

Use the Share button to collaborate, just like in Google Docs. Set viewer, commenter, or editor roles.

🔢 Practice Activity:

Create a basic budget tracker or task list using columns, formulas, and formatting.

🖼️ Module 4: Google Slides (PowerPoint Alternative)

Objective: Use Google Slides for creating engaging presentations.

➕ New Presentation

Create a new presentation from slides.google.com.

🎨 Slide Layouts & Themes

Select pre-made layouts or themes for a professional look.

🎥 Add Text, Images, Shapes, and Videos

Drag and drop content to enrich your presentation.

💨 Animations & Transitions

Apply transitions between slides and animate specific items.

🎤 Presenting and Sharing

Click Present to view your slides. Use Share for collaboration.

📄 Exporting

Download your presentation as a .ppt or PDF.

📚 Practice Activity:

Create a 5-slide presentation about a topic you like. Include at least one image and animation.
